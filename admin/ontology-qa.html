⚖️ 5대 엄격 분리 원칙 (5 Canonical Separation Principles)

1. Body != Emotion

`가슴 철렁`은 생리적 감각(Body Signal)이며, `불안/두려움`(Emotion)으로 뭉개지 않고 분리합니다.

✓ ENFORCED
2. Urge != Action

`확인하고 싶은 충동`(Urge)과 실제 `휴대폰을 열어본 행위`(Action)를 절대 동일 노드로 취급하지 않습니다.

✓ ENFORCED
3. Scene != Trigger

상황적 장면(`엄마와의 통화`)과 자극 신호(`엄마의 부탁`)를 분리하여 과잉 일반화를 방지합니다.

✓ ENFORCED
4. Story != Fact

객관적 현실(`계약 취소 통보`)과 머릿속 이야기(`나는 실패자다`)를 혼동하지 않도록 구별합니다.

✓ ENFORCED
5. Function != Strength

무의식적 방어 기능(`관계 갈등 회피`)과 내담자의 본래 자원(`배려심`)을 분리하여 존중합니다.

✓ ENFORCED
