명심코칭 도서 시리즈
전체 목차 & 핵심 챕터 공개

무의식의 자동반응(Dark)에서 인지행동 재학습(Neural), 순수 자각(Meta·Zero), 그리고 삶으로의 귀환(THE SHIFT)까지.
향후 출간될 전 권의 상세 Part와 장(Chapter) 목차를 웹사이트에서 바로 읽어보실 수 있습니다.

BOOK 01 출시 완료 (발간)

《다크 코드 (Dark Code)》

부제: 왜 나는 알면서도 반복하는가 — 무의식적 자동반응의 심층 해체

💬 다크 코드의 핵심 질문: “왜 중요한 일일수록 더 예민해질까? 왜 결국 내가 다 하게 될까? 오래된 보호행동이 어떻게 오늘의 나를 가두고 있는가?”
PART 1. 무의식의 자동반응

알면서도 같은 선택을 하는 이유

  • • 01장. 알면서도 같은 선택을 반복하는 뇌
  • • 02장. 과거의 성공 전략이 오늘날의 덫이 될 때
  • • 03장. 보호행동의 역설: 지키려 할수록 잃는다
PART 2. 5대 다크 패턴의 해체

나를 옭아매는 5가지 무의식 코드

  • • 04장. 확인·통제형: 불안을 통제로 덮다
  • • 05장. 직접수행형: “내가 해야 빠르다”의 함정
  • • 06장. 완벽기준형: 100점 아니면 실패라는 왜곡
  • • 07장. 기회집착형: 놓치는 것에 대한 공포(FOMO)
  • • 08장. 과잉책임형: 남의 짐까지 짊어지는 습관
PART 3. 일과 관계의 병목

리더십과 소통에서 드러나는 그림자

  • • 09장. 모든 결정을 쥐고 있는 사람의 번아웃
  • • 10장. 대화의 트리거: 상대의 한마디에 켜지는 방어
  • • 11장. 인정욕구와 끊임없는 증명의 피로감
PART 4. 에너지의 전환

다크에서 뉴럴로 가는 관문

  • • 12장. 코드를 없애지 않고 알아차리기
  • • 13장. 같은 힘의 다른 사용법을 준비하며
  • • 14장. 나를 고치기 전에 먼저 이해하기
BOOK 02 출시 예정 (출간 준비 중 • 32개 장 완제)

《뉴럴 코드 (Neural Code)》

부제: 이제 이 에너지를 어떻게 다르게 사용할 것인가 — 행동 재학습 실전서

💬 뉴럴 코드의 제1원칙: “다르게 느껴져야 다르게 행동하는 것이 아니다. 다르게 행동하면서 비로소 다르게 배운다. 내 안에서 일어나는 충동은 나의 경험이지만, 나의 명령은 아니다.”
PART 1. 반응과 선택 사이의 거리

내 안의 신호를 읽고 즉시 반응하지 않는 자유

  • • 1장. 자동반응은 왜 이렇게 빠른가
  • • 2장. 감정은 진짜지만 해석까지 사실은 아니다
  • • 3장. “불안한 사람”에서 “불안이 올라오고 있다”로
  • • 4장. 생각을 생각으로 볼 수 있다는 것 (메타인지)
  • • 5장. 몸은 생각보다 먼저 반응한다 (신체 경고등)
  • • 6장. 충동과 행동 사이의 시간 (바로 하지 않는 자유)
PART 2. 생각과 싸우지 않고 빠져나오기

ACT 탈융합과 인지적 유연성의 기술

  • • 7장. 생각을 없애려 할수록 더 커지는 이유
  • • 8장. ACT의 탈융합: 생각에서 한 걸음 물러서기
  • • 9장. FACT(사실)와 STORY(해석)를 나누는 연습
  • • 10장. 마음이 붙인 제목을 바꾸어본다
  • • 11장. 낙관이 아닌 더 유연하고 행동 가능한 해석
PART 3. 오래된 패턴을 이기는 행동실험

가장 강한 논리는 실제로 다르게 살아본 경험이다

  • • 16장. “내가 해야 빠르다”를 시험해본다
  • • 17장. “거절하면 버림받는다”를 시험해본다
  • • 18장. “완벽하지 않으면 끝이다” (80점 제출 실험)
  • • 19장. “쉬면 뒤처진다” (아무것도 생산하지 않는 시간)
  • • 20장. 안전은 무사고가 아닌 회복 가능성이다
PART 4. 같은 힘을 다른 방식으로 (핵심)

코드를 없애지 않고 에너지를 재사용한다

  • • 21장. 통제력을 정확성으로 바꾼다 (통제 → 기준)
  • • 22장. 완벽주의를 품질감각으로 (완벽 → 정밀)
  • • 23장. 과잉책임을 신뢰할 수 있는 책임감으로
  • • 24장. 인정욕구를 가치의 건강한 표현으로
  • • 25장. 경쟁을 성장의 에너지로 바꾼다
  • • 26장. 회피를 전략적 거리두기로 바꾼다
  • • 27장. 분노를 명료한 경계의 언어로 바꾼다
  • • 28장. 불안을 준비의 능력으로 바꾼다
PART 5. 내가 중요하게 여기는 방향으로

평가가 아닌 가치로 인생을 결정한다

  • • 25장. “사람들이 나를 어떻게 볼까”에서 가치로
  • • 26장. 원하는 결과와 원하는 삶은 다를 수 있다
  • • 27장. 두려움이 사라지기를 기다리지 않는다
  • • 28장. 큰 변화보다 10% 다른 작은 행동실험
  • • 30장. 선택에는 포기가 포함된다 (NO의 힘)
PART 6. 새로운 경험이 예측을 수정한다

설명보다 실제 경험이 뇌를 바꾼다

  • • 31장. 마음은 설명보다 경험에서 배운다
  • • 32장. 맡겨도 일이 끝난다는 것을 배운다 (위임)
  • • 에필로그. 이미 가진 힘의 사용법을 다시 배운 당신에게
BOOK 03 출시 예정 (집필 진행 중)

《메타 코드 (Meta Code) · 제로 포인트》

부제: 알아차림 자체가 자각될 때 무엇이 달라지는가 — 심층 의식 탐구

💬 메타 코드의 정점: “생각도, 감정도, 그것을 바라보는 관찰자 감각까지 지금 알아차림 안에 나타난다. 지금 이 순간, 알아차리고 있음 자체가 자각되는가?”
PART 1. 생각하는 나, 보는 나
  • • 01장. 일상적 메타인지와 순수 자각의 경계
  • • 02장. 관찰자 자아의 발견과 거리두기
  • • 03장. 생각과 나를 동일시하던 감옥에서의 탈출
PART 2. Zero Point의 발견
  • • 04장. 자각 자체가 자각되는 영점(Zero Point)
  • • 05장. 모든 판단과 조건이 멈추는 순수한 자리
  • • 06장. 상황을 있는 그대로 허용하는 힘
PART 3. 초월의 함정을 넘어
  • • 07장. 깨달음을 핑계로 삶을 회피하는 위험
  • • 08장. 뉴럴 코드(재학습) 없는 메타의 맹점
  • • 09장. 삶을 건너뛰지 않고 현실로 통합하기
PART 4. 제로 포인트에서의 선택
  • • 10장. 이 자리에서 지금 무엇을 선택할 것인가
  • • 11장. SHIFT: 삶의 현장으로 돌아오는 첫 움직임
SPECIAL EDITION 출시 예정 (통합 실전 응용서)

《THE SHIFT (더 시프트)》

부제: 알아차림을 삶의 선택으로 바꾸는 3S 실전 프로토콜

💬 THE SHIFT의 정의: “판을 바꾸지 못해도, 판을 대하는 나는 자유로울 수 있다. SHIFT는 인생을 통제하는 기술이 아니라, 주어진 판에서 자유롭게 노는 능력이다.”
PART 1. SHIFT의 본질
  • • 01장. Dark 갇힘 → Neural 배움 → Meta 자각 → SHIFT
  • • 02장. 이겨야만 하는 게임에서 자유로운 놀이로
  • • 03장. 현실은 그대로 두고 관계 방식을 바꾼다
PART 2. 3S 실전 프로토콜
  • • 04장. SCAN: 오래된 자동 충동을 즉시 알아차린다
  • • 05장. SYNC: Zero Point에서 나의 본질적 가치와 정렬
  • • 06장. SHIFT: 새로운 관점으로 현실에 귀환한다
PART 3. 현장 실전 적용
  • • 07장. 일과 비즈니스: 통제 대신 명료한 기준 세우기
  • • 08장. 갈등과 대화: 상대를 바꾸려 하지 않는 대화
  • • 09장. 리더십: 혼자 다 하지 않고 전체 흐름 보기
PART 4. 자유로운 삶으로 귀환
  • • 10장. 삶을 지나치게 꽉 붙잡지 않는 가벼움
  • • 11장. 매 순간 새롭게 선택하는 예술
  • • 12장. 일상에서 완성되는 명심코칭의 여정

08 《지지 뉴럴 코드》 지지의 에너지를 어떻게 새롭게 사용할 것인가 집필 예정
09 《지지 메타 코드》 지지의 작동을 알아차리되 거기에 갇히지 않는 법 집필 예정
10 《60갑자 다크 코드》 천간과 지지가 만나 어떤 반복 장르가 만들어지는가 집필 예정

13 《십성 다크 코드》 내 욕망과 관계의 자동동력은 무엇인가 집필 예정

Our Vision

인간의 마음을 이해하고,
성장의 한계를 넘어서는 도구를 만듭니다.

마인드플로우랩은 '마음의 흐름(Mindflow)'이란 보이지 않는 추상적 개념이 아닌, 데이터와 인지 패턴을 통해 측정하고 긍정적인 방향으로 유도할 수 있는 과학적 시스템이라고 믿습니다.

01

인지과학 기반 접근

단순 암기나 일시적 위로가 아닌, 사람이 정보를 받아들이고 정서를 처리하는 인지 구조적 메커니즘을 심층 분석하여 시스템을 설계합니다.

02

데이터 기반 맞춤형 설계

학습자의 오답 패턴, 스트레스 반응 수치, 일상 라이프로그를 유기적으로 결합하여 가장 최적화된 맞춤형 성장 피드백을 전달합니다.

03

실용적 디지털 도구 개발

연구실에 갇힌 이론에 머무르지 않고, 스마트폰 앱과 모바일 인터페이스를 통해 누구나 일상에서 손쉽게 혜택을 누릴 수 있는 제품을 출시합니다.
