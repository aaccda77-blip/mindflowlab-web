CODE 01 PROTOCOL: SCAN

DARK CODE × SCAN

“나는 원래 이런 사람이야”에서 패턴을 발견하다

다크코드(Dark Code)는 나쁜 코드나 결함이 아닙니다. 오랜 시간 반복되어 너무 익숙해진 나머지 어느 순간부터 ‘나 자체’라고 믿게 된 사고·감정·행동의 자동패턴입니다.

• “나는 원래 예민해.”
• “나는 원래 사람을 못 믿어.”
• “나는 원래 인정받아야 해.”
• “나는 원래 화가 나면 참지 못해.”

이때 우리는 하나의 반응패턴을 경험하는 것이 아니라 ‘그 생각이 곧 나’가 되고, ‘그 감정이 곧 나’가 됩니다.

🔍 이것이 SCAN입니다: 다크코드를 없애기 전에 먼저 봅니다. 판단하지 않고, 고치려고 서두르지 않고, “아, 내 안에서 지금 이 패턴이 자동으로 작동하고 있구나.” 하고 알아차립니다.
CODE 02 PROTOCOL: SYNC

NEURAL CODE × SYNC

패턴은 나의 전부가 아니다 (탈동일시)

뉴럴코드(Neural Code)는 다크코드를 제거하는 과정이 아닙니다. “이런 패턴이 내 안에 있다는 것을 인정하면서도, 이것이 나의 전부는 아니다.”라고 바라보는 힘입니다.

“나는 불안한 사람이다”
👉 “지금 내 안에 불안이라는 경험이 일어나고 있다.”
“나는 실패자다”
👉 “지금 내 마음이 나에게 실패자라는 이야기를 하고 있다.”

DBT의 수용과 변화, ACT의 심리적 유연성, MBCT의 탈중심화, MSC의 자기연민을 활용하여 오래된 패턴까지도 “그럴 수밖에 없었던 나의 한 부분”으로 품습니다.

🔄 이것이 SYNC입니다: 내 기질과 싸우지 않고 조율합니다. 자동적인 반응 대신 새로운 선택을 반복하면서 유연한 사고와 행동방식을 스스로 학습해 갑니다.
CODE 03 PROTOCOL: SHIFT

META CODE × SHIFT

알아차림을 알아차리다 (Zero Point)

메타코드(Meta Code)는 결점이 없는 상태가 아닙니다. 생각도 여전히 일어납니다. 감정도 올라옵니다. 때로는 다크코드도 다시 작동합니다.

그것이 일어나고 있다는 사실을 알아차립니다.
그리고 한 단계 더 깊어지면, ‘내가 지금 알아차리고 있다는 것’까지 알아차립니다.

책 《제로포인트》가 말하듯, 다크코드와 메타인지를 넘어 내면의 현상을 바라보는 근원적인 관찰의 자리로 돌아옵니다.

⚡ 그 순간 비로소 SHIFT가 가능합니다: 생각이 있어도 갇히지 않고, 감정이 있어도 휩쓸리지 않습니다. SHIFT란 다른 사람이 되는 것이 아니라, 같은 나, 같은 기질을 더 자유롭고 지혜롭게 사용하는 능력입니다.

명심코칭 팩트체크

변화는 거대한 결심보다 다시 꺼낼 수 있는 작은 행동에서 시작됩니다.

유형은 나를 이해하기 위한 지도이지, 내가 평생 살아야 할 주소가 아닙니다.
