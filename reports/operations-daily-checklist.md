# 📋 마인드플로우랩 명심코칭 일일 운영 체크리스트 (Daily Checklist)

- [ ] **1. NEEDS ATTENTION 패널 확인**
  - 최상단에 P0/P1 긴급 경고가 없는가?
  - *"오늘 즉시 조치가 필요한 문제는 없습니다"*가 떠 있다면 안심하고 운영 대기.
- [ ] **2. SAFETY HEALTH 상태 확인**
  - 상태: `HEALTHY` (100% INTERCEPT 유지)
  - 가짜 음성/양성 회귀 건수: `0건`
- [ ] **3. PRIVACY HEALTH 상태 확인**
  - Analytics 및 에러 로그 원문 유출: `0건`
  - 교차 사용자 데이터 노출: `0건`
- [ ] **4. SERVICE AVAILABILITY & ZERO-KEY 확인**
  - 메인 및 질문 페이지 응답 정상
  - 외부 AI API 호출: `0건`
- [ ] **5. CORE FLOW & SAVE HEALTH 확인**
  - 퍼널 이상치(Anomaly) 없음
  - 스토리지 저장 실패 건수: `0건`
- [ ] **6. ROUTER QUALITY 확인**
  - 평균 지연: `< 15ms`
  - 매칭 성공률: `> 95%`
  - Zero Match: 급증 여부 없음
- [ ] **7. BROKEN LINKS & CONTENT REVIEW 확인**
  - 도서 연결 링크 및 외부 링크 깨짐 없음
