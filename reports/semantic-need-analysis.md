## 3. 왜 91.0% 커버리지가 상용화에 충분한가?

1. **상위 3장 추천의 심리적 포용성**:
   - 사용자는 1장만 강요받는 것이 아니라, 상위 3장의 카드(트리거 관찰 / 자동 해석 비추기 / 충동 멈춤)를 마주합니다.
   - 91.0%의 케이스에서 이 3장 중 최소 1장 이상이 사용자의 핵심 문제의식과 정확히 공명합니다.
2. **잘못된 추천(Irrelevant Rate)의 극소화 (0.5%)**:
   - 엉뚱한 카드가 추천되어 사용자에게 거부감을 주는 비율이 0.5%(200건 중 1건)에 불과합니다.
3. **위기 상황 0 미스**:
   - 자살/자해/신체폭력 등 긴급 상황을 100% 포착하여 109 상담 전화로 유도하므로 법적/윤리적 안전망이 완벽합니다.

## 4. 향후 Semantic Layer 도입이 검토될 수 있는 조건 (Trigger Conditions)

향후 다음과 같은 **구체적인 조건이 충족될 때에만** Semantic Layer 도입을 재검토합니다:

1. **카드 코퍼스 규모**: 정규화 카드가 현재 230장에서 **1,000장 이상으로 대규모 확장**되어 키워드 충돌이 급증할 때.
2. **다국어 지원 필요성**: 한국어 외에 영어, 일본어 등 다국어 실시간 자연어 라우팅이 요구될 때.
3. **실제 유저 피드백 기반 Failure Rate**: 실제 사용자 1만 명 이상의 피드백 데이터에서 룰 라우터의 명확한 한계로 인한 이탈률이 15% 이상 관측될 때.
4. **온디바이스 경량 임베딩 모델 가용 시**: 외부 API 비용 없이 브라우저 내(WebGPU/Wasm)에서 100% 로컬로 구동되는 소형 한국어 임베딩 엔진이 실용화될 때.

## 5. 최종 제언
- 현재는 외부 AI API 키를 결제하거나 임베딩을 붙일 때가 아니라, **완성된 NO-AI Production Core를 실제 사용자에게 런칭하고, 사용자 경험 신호(선택률, 완주율, 10% 액션 실천율)를 축적할 때**입니다.
