# 명심코칭 개인 홈 v2 모바일 QA 및 반응형 검증 보고서
(MYUNGSIM PERSONAL HOME v2 MOBILE & RESPONSIVE QA REPORT)

> **모바일 기준 규격:** 390px × 844px (iPhone 14 / 최신 표준 스마트폰 뷰포트)

---

## 1. 뷰포트 첫 화면(First Fold) 사용자 경험 검증

모바일 화면(390×844)에서 접속 시 사용자가 스크롤을 내리지 않고도:
- **오늘 무엇이 마음에 걸리나요?** 타이틀 및 Textarea 입력창
- 또는 **지난번 선택: 어떻게 됐는지 기록하기** Primary CTA
둘 중 하나가 100% 첫 화면(Above the Fold)에 노출됨을 확인했습니다.

```text
+------------------------------------------+ (390px)
| [🌱 명심 개인 홈]           [여행자] [로그아웃] |
+------------------------------------------+
| PAST → PRESENT → NEXT                    |
| 오늘은 어떤 장면이 가장 마음에 걸리나요?       |
| [ Textarea: 오늘 마음에 걸리는 장면...     ] |
| [🔗 지난 발견과 연결해서 볼까요? [스위치]  ] |
| [ 🌱 가까운 질문 찾기 &rarr; (Primary CTA) ] |
+------------------------------------------+ <--- 500px 기준점
| [ 지난번 선택 (Active Experiment) ]      |
+------------------------------------------+
| [🏡 홈]   [🔍 탐색]   [🌱 실험]   [🗺️ 지도] | <--- Bottom Nav 고정
+------------------------------------------+ (844px)
```

---

## 2. 모바일 인터랙션 및 터치 타깃 QA 결과

1. **최소 터치 영역 (44px Rule)**:
   - Primary CTA, Secondary 버튼, Bottom Navigation 아이콘 모두 최소 44px 이상의 탭 타깃 확보 완료.
2. **과도한 정보 밀도 방지 (Anti-Clutter)**:
   - 한 화면에 7개 대시보드를 빽빽하게 채우지 않고, 여백(Margin)과 둥근 카드(Rounded-3xl)를 활용해 심리적 안정감 제공.
3. **Bottom Nav 고정 바**:
   - `position: fixed; bottom: 0;` 및 `backdrop-filter: blur(8px)`를 적용하여 본문 스크롤 시에도 최하단 네비게이션이 부드럽게 유지됨.
   - 본문 컨테이너에 `pb-24` 패딩을 적용하여 최하단 컨텐츠가 네비게이션 바에 가려지지 않음.
