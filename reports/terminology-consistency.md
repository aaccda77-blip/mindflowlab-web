# 마인드플로우 랩 핵심 용어 일관성 감사 보고서 (Terminology Consistency Report)
**문서 버전:** v1.0  
**작성 일자:** 2026-09-21  
**기준 파일:** `js/myungsim-design-system.js` & `docs/myungsim-terminology.md`  
**결과:** INCONSISTENT CORE TERMS: 0 (용어 불일치 0건)

---

## 1. 개요

명심코칭의 가장 중요한 핵심 개념들인 `SCAN`, `SYNC`, `SHIFT`, `10% ACTION`, `Dark Code`, `Neural Code`, `Zero Point`가 페이지마다 제각각 다르게 설명되지 않고, 하나의 일관된 철학적 정의로 유지되는지 전수 점검하였습니다.

---

## 2. 핵심 용어 정의 일관성 검증표

| 핵심 용어 | 표준 제품 언어 | 일관성 검증 내용 | 판정 |
| :--- | :--- | :--- | :---: |
| **SCAN** | “지금 무슨 일이 일어나고 있는지 잠깐 확인합니다.” | 심리검사나 성격 진단으로 오도되지 않음을 확인 | **PASS** |
| **SYNC** | “지금 이런 반응이 있구나.” | 반응을 인정하되 나 전체로 삼지 않는 문구 유지 | **PASS** |
| **SHIFT** | “그럼 다음에는 무엇을 10% 다르게 해볼까요?” | 각성이나 치유가 아닌 10% 다른 행동에 집중 | **PASS** |
| **10% ACTION** | “오늘 가능한, 조금 다른 선택” | 미션, 숙제, 극복 챌린지 등의 강제어 0건 확인 | **PASS** |
| **Dark Code** | “반복되는 자동 작동” | 결함이나 나쁜 코드, 병리적 낙인 0건 확인 | **PASS** |
| **Neural Code** | “새로운 경험을 만드는 연습” | 뇌 재배선이나 신경회로 치료 등의 과장 0건 확인 | **PASS** |
| **Zero Point** | “반응과 나 사이의 작은 선택공간” | 영적 레벨, 최고 각성 단계 등 신비주의 0건 확인 | **PASS** |
| **STORY** | “사실이 확인되기 전에 머릿속에서 만든 해석” | 거짓말이나 왜곡사고라는 매도 0건 확인 | **PASS** |
| **UNKNOWN** | “아직 모르는 것” | 회피가 아닌 정확성의 공간으로 설명됨을 확인 | **PASS** |
| **BODY** | “몸에서 먼저 올라오는 신호” | 신체 감각을 위험의 증거로 삼지 않음을 확인 | **PASS** |

## 3. 결론

제품 전체에서 핵심 개념의 의미가 단일 소스(`MyungsimDesignSystem`)에 의해 관리되며, 페이지나 기능이 늘어나더라도 사용자가 느끼는 개념의 혼란이 완전히 제거되었음을 확인합니다.
