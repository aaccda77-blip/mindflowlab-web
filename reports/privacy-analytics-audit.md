## 2. 세부 영역별 감사 결과

### 2.1 사용자 텍스트 원문 미수집 검증
- **검색창 입력 문장:** 사용자가 명심AI 검색창에 입력한 고민 문장 원문은 외부 데이터베이스나 백엔드로 전송되지 않으며, 클라이언트 사이드 자바스크립트 엔진(`MyeongsimAIRouter`) 내에서만 인메모리로 처리됩니다.
- **1분 SCAN 작성 메모:** 사용자가 카드를 보며 작성하는 FACT, STORY, UNKNOWN, 10% 실천 계획 메모는 서버 전송 없이 브라우저 메모리에만 존재하며 페이지 새로고침 시 초기화됩니다.
- **네트워크 페이로드 검사:** Chrome DevTools Network 탭 및 네트워크 요청 전수 검사 결과, 사용자 입력 텍스트가 쿼리스트링이나 POST Body에 포함되어 전송되는 요청이 **전혀 없음(0건)**을 확인하였습니다.

### 2.2 LocalStorage 보관 데이터 감사
브라우저 로컬 스토리지에 영구 또는 임시 저장되는 데이터는 오직 사용자의 편의를 위한 비민감 설정값으로 제한됩니다:

| 스토리지 키 | 데이터 내용 | 민감도 | 보유 기간 |
|---|---|---|---|
| `myungsim_recent_cards` | 최근 열람한 카드 ID 목록 (최대 10개, 예: `["rel-001", "money-005"]`) | 낮음 | 브라우저 캐시 삭제 시까지 |
| `myungsim_audio_muted` | BGM 음소거 여부 (`true` / `false`) | 없음 | 영구 |
| `myungsim_last_visit` | 방문 일자 타임스탬프 | 없음 | 영구 |

*사용자 식별 번호(UID), 이메일, 전화번호, 고민 본문 등은 LocalStorage에 일체 저장되지 않습니다.*

### 2.3 Analytics 이벤트 메타데이터 감사
서비스 품질 개선과 UX 최적화를 위해 수집되는 Analytics 이벤트는 개인을 식별할 수 없는 익명화된 통계 메타데이터만을 전송합니다:

```javascript
// Analytics 허용 이벤트 예시 (비민감 메타데이터)
trackEvent('card_open', { cardId: 'rel-001', category: '관계·심리', pack: 1 });
trackEvent('action_click', { cardId: 'rel-001', actionType: '10_percent_select' });
trackEvent('tab_switch', { tabName: 'daily_recommend' });
trackEvent('safety_triggered', { riskType: 'high_risk' }); // 쿼리 원문 제외, 타입만 기록
```

**금지 사항 준수 확인:**
- [x] 고민 문장 전체를 이벤트 프로퍼티로 전송하지 않음.
- [x] 사용자 작성 메모를 이벤트 프로퍼티로 전송하지 않음.
- [x] IP 주소 및 사용자 기기 식별자를 저장하지 않음.
