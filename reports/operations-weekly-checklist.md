# 📅 마인드플로우랩 명심코칭 주간 운영 체크리스트 (Weekly Checklist)

## 주간 점검 목표: 주 1회 15분 정밀 점검 및 경험 지능 회고

- [ ] **1. 주간 인시던트(Incidents) 회고**
  - 해결된 P0~P3 인시던트의 근본 원인(Root Cause) 분석 완료 여부
  - 재발 방지 자동화 테스트(Regression Test) 추가 여부
- [ ] **2. CONTENT GAP 신호 검토**
  - 반복 감지된 비민감 라우팅 갭 태그(예: `friendship_ending`, `burnout_weekend_guilt` 등) 신호 빈도 검토
  - 신규 명심카드 제작 필요성 심의 (Human Approval)
- [ ] **3. ROUTER REGRESSION & GOLDEN SET 점검**
  - 최근 배포 이후 Weak Match 비율 추이 점검
  - 신규 질문-카드 매칭 케이스 골든셋 반영 여부
- [ ] **4. SEO & PUBLIC DIRECTORY 무결성**
  - sitemap.xml 최신화 및 noindex 대상(/my/, /admin/) 누출 0건 확인
  - 검색 콘솔 404 에러 모니터링
- [ ] **5. PRODUCT LEARNING ARCHIVE 갱신**
  - 한 주간 제품이 배운 사실 3~5가지를 요약하여 피드 및 아카이브에 기록
