# 마인드플로우 랩 프라이버시 및 데이터 철학 규약 (Privacy Language System)
**문서 버전:** v1.0  
**작성 일자:** 2026-09-21  
**기준 파일:** `js/myungsim-design-system.js`

---

## 1. 프라이버시 핵심 카피 (Privacy Copy)

제품 내의 개인 기록 화면, 저장 확인창, 데이터 안내 팝업에는 다음 표준 문구만을 일관되게 사용합니다:

1. **분리 저장 원칙:**
   > “당신의 개인 기록은 공개 콘텐츠와 완전히 분리되어 브라우저에 안전하게 보관됩니다.”
2. **이용 신호 최소화 원칙:**
   > “서비스 개선에는 개인의 고민 원문 대신, 선택된 카드 번호와 같은 최소한의 익명 이용 신호만을 사용합니다.”
3. **원문 보호 원칙:**
   > “개인의 일기나 고민 텍스트는 제품 분석 서버로 전송되지 않습니다.”

---

## 2. 데이터 철학 선언문 (Data Philosophy)

신뢰(Trust) 페이지 및 윤리 헌장(`ethics.html`)에 명시되는 마인드플로우 랩의 영구적 데이터 철학:

> **“사람의 비밀을 축적하지 않고,  
> 사람들의 사용에서 배운 지혜를 축적합니다.”**

### 3대 실천 지침:
1. **No Profiling (개인 프로파일링 금지):** 사용자의 고민 데이터를 모아 인물 프로필을 생성하거나 광고 타겟팅으로 활용하지 않습니다.
2. **Local Sovereignty (로컬 주권):** 사용자의 브라우저 로컬 스토리지에만 저장되며, 사용자가 원할 때 언제든 즉시 단 한 번의 클릭으로 영구 삭제할 수 있습니다.
3. **Zero Raw Text Transmission (원문 전송 0건):** 분석 이벤트 파이프라인(`trackSafeJourneyEvent` 등)은 화이트리스트 검사를 통해 사용자의 주관식 원문 텍스트를 전송 전 100% 삭제(delete)합니다.
