# 🏢 명심코칭 비즈니스 연속성 지침 (Business Continuity Plan)

## 1. 최소 유효 서비스 (Minimal Viable Service, MVS) 정의
최악의 재해 상황(클라우드 DB 전면 장애, 스토리지 크래시 등)에서도 명심코칭이 지켜야 할 **타협할 수 없는 핵심 사용자 가치**는 다음과 같습니다.

1. **공개 질문 및 200개 명심카드 읽기**: 사용자가 필요할 때 질문을 찾고 카드의 통찰을 읽을 수 있어야 함.
2. **SODA 프레임워크 기반 1분 성찰**: 멈춤-관찰-해체-행동의 인지적 환기 제공.
3. **Safety 안전망 최우선 연결**: 자해/자살, 폭력, 금융, 의료 고위험 상황에 대한 긴급 상담 안내.

> 개인 작동지도나 30일 여정이 일시적으로 중단되더라도, 명심코칭의 핵심 가치는 완전히 보존됩니다.

## 2. 5대 비즈니스 연속성 운영 모드 (Continuity Modes)

### 1) NORMAL (전체 정상)
- 모든 공개 화면, 라우터, SCAN, 행동실험, 개인 홈, 작동지도, 여정, 분석 기능이 풀 가동되는 표준 상태.

### 2) DEGRADED (부분 격리)
- Working Map이나 30일 여정 관련 버그/지연 발생 시 해당 기능만 서킷 브레이커로 숨기고, 1분 SCAN 및 핵심 코어 플로우는 완벽히 유지.

### 3) READ_ONLY (읽기 전용 / 저장 점검)
- DB 쓰기 오류나 스토리지 Quota 장애 발생 시 활성화.
- 사용자가 작성한 내용이 저장되었다고 거짓 표시(False Confirmation)하지 않고, *"현재 저장 기능을 점검 중입니다. 화면의 카드는 자유롭게 읽으실 수 있습니다"*라고 정직하게 고지.

### 4) STATIC_EMERGENCY (최소 정적 비상)
- 모든 백엔드 및 동적 스크립트 장애 시 순수 HTML 기반 정적 페이지(홈, 질문, 안전 안내)만 제공.

### 5) MAINTENANCE (긴급 전체 점검)
- 전사 데이터 마이그레이션 또는 P0 보안 패치 적용 시 운영자 승인 하에 일시적 점검 화면 노출.
