## 1. 표준 CTA 사전 (Core CTA Dictionary)

제품 전체에서 유사한 의미로 난립하던 버튼 이름을 다음 공식 사전으로 100% 통일합니다.

| 분류 (Flow) | 표준 CTA 명칭 | 용도 및 화면 위치 | 통합된 이전 표현들 |
| :--- | :--- | :--- | :--- |
| **First Entry** | **오늘의 카드 뽑기** | 랜딩 / 탐색 첫 진입 Primary | 카드 고르기, 오늘 운세, 카드 보기 |
| **First Entry** | **내 고민으로 질문 찾기** | 검색창 / AI 라우터 진입 | 고민 입력, 질문 검색, AI 분석 |
| **Router** | **가까운 질문 찾기** | 라우터 결과 탐색 CTA | 질문 추천, 분석하기, 카드 찾기 |
| **Router** | **이 질문으로 보기** | 특정 추천 질문 선택 | 상세 보기, 질문 열기, 바로가기 |
| **SODA / Flow**| **내 경우를 1분 SCAN** | 질문 상세에서 SCAN 진입 Primary | 내 경우 보기, 내 패턴 보기, SCAN 시작, 적용하기 |
| **SCAN Step** | **다음** | SCAN 스텝 간 순차 이동 | 계속하기, 다음 단계, GO |
| **Action Step**| **오늘의 10% 선택** | 10% 행동 옵션 선택 완료 CTA | 행동 고르기, 실천하기, 적용 |
| **Save** | **오늘 발견 저장하기** | 개인 기록 보관함 저장 | 저장, 기록 완료, 보관 |
| **Experiment** | **작은 행동실험으로 남기기** | 행동실험 루프로 연결 | 실험하기, 루프 시작, 미션 등록 |
| **Follow-up** | **어떻게 됐는지 보기** | 실제 결과 입력 및 비교 CTA | 결과 입력, 피드백, 확인하기 |
| **Working Map** | **내 작동지도 보기** | Personal Working Map 이동 | 지도 보기, 내 패턴 확인, 마이맵 |
| **Journey** | **30일 여정 시작** | 30-Day Guided Journey 진입 | 30일 챌린지, 습관 시작, 여정 등록 |
| **History** | **전체 기록 보기** | 누적 관찰 세션 목록 조회 | 히스토리, 이전 기록, 지난 기록 |
| **Session End** | **여기서 끝내기** | 세션 종료 및 일상 복귀 CTA | 그만두기, 종료, 닫기 |
| **Session End** | **이걸로 충분해요** | 세션 종료 (심리적 안도감 부여) | 완료, 나가기 |

## 2. Primary / Secondary CTA 배치 규칙

1. **화면당 Primary CTA는 엄격히 최대 1개:**
   - 한 화면에 강한 에메랄드색 Primary 버튼이 2개 이상 나열되면 사용자는 인지적 혼란을 겪습니다.
   - 핵심 행동 1개만 Primary로 지정합니다.
2. **Secondary CTA는 최대 1~2개:**
   - 서브 액션은 흰색 바탕의 `.btn-secondary` 또는 링크 형태의 `.btn-ghost`로 배치합니다.
3. **버튼 5~6개 나열 금지:**
   - 한 화면에 여러 개의 버튼을 무더기로 늘어놓지 않습니다.

---

## 3. 버튼 동사 명확성 규칙 (Verb-Oriented)

의미가 불분명한 단순 일반어(generic terms)는 최소화합니다.

- ❌ **불명확한 버튼 (Bad):** `확인`, `계속`, `시작`, `GO`, `적용`
- ⭕ **명확한 행동 동사 (Good):** `질문 찾기`, `1분 SCAN`, `행동 선택`, `기록 보기`, `지도 보기`

---

## 4. 일상 복귀를 위한 Exit CTA 강제

모든 Core Flow(SCAN, 행동실험, 30일 여정)의 마지막에는 사용자를 앱에 억지로 붙잡아두지 않고 삶의 현장으로 돌려보내는 **Exit CTA**가 반드시 존재해야 합니다:

- `여기서 끝내기`
- `이걸로 충분해요`
- `오늘은 여기까지면 충분합니다. 가벼운 마음으로 일상으로 돌아가세요.`
