# MyungSim Concept Privacy Specification
**문서:** 개인정보 보호 및 Zero-Log 정책  
**버전:** v3.0  

---

## 1. Zero-Log 원칙

명심코칭의 인프라와 엔진은 사용자의 사적 사연과 검색어를 절대 영구 저장하지 않습니다.

1. **`rawQuery` 저장 금지**:
   - 사용자가 입력한 날것의 문장은 라우팅 함수 실행 중 메모리에만 일시 존재하며, 반환 객체나 로그 파일에 영구 기록되지 않습니다.
2. **`normalizedQuery` 외부 전송 금지**:
   - 오타가 교정된 정규화 문장 역시 로컬 함수 스코프 내에서만 처리되며 브라우저 외부로 유출되지 않습니다.
3. **익명화 통계 집계만 허용**:
   - 집계 가능한 데이터는 온톨로지 정규 노드의 빈도수(예: `TRIG_MESSAGE_NO_REPLY` 카운트 $+1$)뿐이며, 개별 사용자의 IP, 쿠키, 세션 ID와 결합되지 않습니다.

---

## 2. PII 및 민감정보 비유출 보증

- 브라우저 인메모리 실행 구조로 인해 외부 LLM 제공업체(OpenAI, Anthropic, Google Cloud 등)로 일체의 텍스트 페이로드가 전송되지 않습니다.
- 프라이버시 감사 스크립트를 통해 스토리지 및 네트워크 요청에 `rawQuery`가 포함되지 않음을 100% 지속 검증합니다.
