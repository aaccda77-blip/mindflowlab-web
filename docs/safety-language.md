# 마인드플로우 랩 안전 라우팅 언어 규약 (Safety Language System)
**문서 버전:** v1.0  
**작성 일자:** 2026-09-21  
**기준 파일:** `js/myungsim-design-system.js`  
**원칙:** CURRENT SAFETY > PAST PATTERN (현재 안전이 과거의 어떤 여정 흐름보다 최우선)

---

## 1. 개요

사용자의 생명과 안전이 걸린 고위험(High-Stakes) 상황에서 명심코칭은 일체의 카드 뽑기, 철학적 은유, 동기부여, 상품(책) 홍보를 중단하고, **명확하고 현실적인 전문 기관의 도움을 최우선으로 연결**합니다.

## 3. 고위험 화면의 CTA 및 UI 규칙

1. **Primary CTA의 절대 규칙:**
   - 고위험 안전 화면의 Primary 버튼은 결코 `카드 다시 뽑기`, `책 보러 가기`, `여정 시작`이 되어서는 안 됩니다.
   - 반드시 **`전화 상담 연결 (109 / 1577-0199)`** 또는 **`가까운 센터 찾기`**여야 합니다.
2. **차분한 시각적 알림 디자인:**
   - 지나치게 형광빛이 도는 붉은색이나 해골, 사이렌 등 공포를 조장하는 그래픽을 배제하고, 차분한 라즈베리/로즈 톤(`.alert-safety`)으로 안내하여 사용자의 패닉을 예방합니다.
3. **사이다 한 줄 요약의 안전 원칙:**
   - “좋은 코칭은 치료가 필요한 순간까지 코칭으로 붙잡아두지 않습니다.”
