# 마인드플로우 랩 콘텐츠 언어 시스템 (Content Language System)
**문서 버전:** v1.0  
**작성 일자:** 2026-09-21  
**버전 태그:** `myungsim-language-v1.0`

---

## 1. 제품 보이스 & 톤앤매너 (Product Voice)

명심코칭의 문체는 사용자를 가르치거나 고치려 들지 않습니다. 친구처럼 차분하고, 법관처럼 공정하며, 거울처럼 투명합니다.

| 긍정적 지향 (Product Voice) | 절대 지양 (To Avoid) |
| :--- | :--- |
| **차분함 (Calm):** 정서적 과열을 가라앉히는 어조 | 감정적 과잉 위로, 호들갑스러운 공감 |
| **짧음 (Concise):** 모바일에서 한눈에 들어오는 문장 | 만연체, 불필요한 사족, 3줄 이상의 장문 단락 |
| **생활언어 (Plain):** 일상에서 누구나 쓰는 쉬운 말 | 난해한 심리학 전문용어, 철학적 난독증 유발 문구 |
| **판정하지 않음 (Non-verdict):** 있는 그대로의 사실 기술 | 정체성 단정, 성격 낙인, 의지력 평가 |
| **과장하지 않음 (Realistic):** 10% 작은 시도의 사실적 기록 | 100% 변화 보장, 완치 약속, 극적인 각성 선언 |
| **현실 인정 (Reality-grounded):** 객관적 사실을 지우지 않음 | "모든 건 당신 마음 탓"이라는 식의 맹목적 내면화 |

## 2. 화면 카피 글자 수 한도 (Copy Limits)

모바일 390px 화면에서 사용자의 인지 부하를 최소화하기 위해 다음 규칙을 엄격히 적용합니다:

1. **Headline (타이틀):** 최대 1~2줄 (공백 포함 30자 이내).
2. **Description (본문 설명):** 최대 2~3줄 (공백 포함 80자 이내).
3. **SODA (사이다 한 줄 요약):** 1~3문장 이내의 명료한 통찰.
4. **WHY (질문 배경):** 1~2문장의 일상적 맥락 설명.
5. **CTA (버튼 명칭):** 2~4단어의 명확한 행동 동사 (예: "오늘의 10% 선택").

## 3. 질문형 문체 원칙 (Inquiry vs Assertion)

사용자에게 성급한 결론이나 판단을 내려주지 않고, 스스로 내면의 작동을 바라볼 수 있는 **"관찰 질문"**을 건넵니다.

- ❌ **단정문 (Bad):** “당신은 남의 시선을 지나치게 의식하는 인정중독자입니다.”
- ⭕ **관찰 질문 (Good):** “상대의 표정이 굳어지면, 내 잘못이라는 생각이 바로 올라오나요?”
- ❌ **단정문 (Bad):** “불안을 억누르려 하지 마세요. 그것은 역효과를 냅니다.”
- ⭕ **관찰 질문 (Good):** “지금 불안을 즉시 없애려고 카톡을 다시 열어보고 싶어지나요?”

---

## 4. 현실 인정 문체 (Reality-Grounded Empathy)

상대방이 실제로 폭력을 행사했거나 반복해서 거짓말을 한 객관적 사실이 있을 때, 이를 “당신의 망상이나 왜곡”으로 취급해서는 안 됩니다.

> “상대가 반복해서 약속을 어겼다면 그 사실 자체는 당신의 STORY(상상)로 줄일 수 없습니다. 다만 그 사실 위에서 내가 나 자신에게 내린 무력한 판결은 따로 떼어내어 볼 수 있습니다.”

## 5. 시스템 상태별 표준 카피 (System States)

### 1) 빈 화면 (Empty State)
- 기록 없음: “아직 저장한 발견이 없습니다.”
- 지도 없음: “반복을 말하기에는 아직 기록이 충분하지 않습니다.”
- 검색 없음: “정확히 같은 질문은 아직 없습니다. 다른 일상 단어로 검색해 보세요.”

### 2) 로딩 상태 (Loading State)
- 질문 탐색: “가까운 질문을 찾고 있습니다.”
- 지도 구성: “최근 기록을 정리하고 있습니다.”
- 🚫 금지: “당신의 심리를 분석 중입니다”, “무의식을 읽고 있습니다”.

### 3) 성공 상태 (Success State)
- ⭕ 허용: “오늘 선택을 저장했습니다.” / “실제 결과를 하나 기록했습니다.” / “최근 지도에 반영했습니다.”
- 🚫 금지: “성공했습니다!”, “패턴을 완전히 깨뜨렸습니다!”.

### 4) 오류 상태 (Error State)
- ⭕ 허용: “질문을 불러오지 못했습니다. 잠시 후 다시 시도해 주세요.”
- 🚫 금지: 500 Internal Server Error 등 기계적 오류 노출.
