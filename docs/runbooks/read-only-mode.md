# 📖 읽기 전용 모드 (Read-Only Mode) 전환 런북

## 1. 개요 및 발동 시점
- 데이터베이스 쓰기 지연, 스토리지 마이그레이션, 복구 작업 진행 중 사용자 입력 내용의 유실을 방지하기 위해 발동합니다.
- **핵심 원칙**: 사용자가 공들여 작성한 고민이나 SCAN 내용이 저장되지 않았는데도 "저장되었습니다"라고 거짓 피드백을 주는 것을 원천 방지합니다.

---

## 2. 사용자 인터페이스 동작

1. **상단 알림 배너**:
   - *"현재 서비스 안정화 점검 중으로, 기록 저장 기능이 일시 중단되었습니다. 명심카드는 자유롭게 읽으실 수 있습니다."*
2. **SCAN 및 행동실험 작성창 비활성화**:
   - 입력 폼은 '읽기 전용'으로 전환되거나, 입력 전 저장 불가 상태를 명확히 고지.
3. **정상 복구 후 해제**:
   - DB 복구 및 무결성 검증 통과 후 운영센터에서 `NORMAL` 모드로 스위칭.
