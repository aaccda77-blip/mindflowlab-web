# MYUNGSIM Launch Day 1 Checklist (첫 24시간 점검표)

## 1. 개요
오픈 당일(H0 ~ H+24)은 서비스의 **기술적 생존성과 무결성**을 확인하는 시기입니다. 사용자의 행동 전환율이나 만족도 지표는 집계하지 않으며 오직 기술 가용성, 개인정보 침해 여부, 응급 안전 모달 정상 작동만을 집중 점검합니다.

---

## 2. 시간대별 집중 점검 타임테이블

### [H+0 ~ H+2] 런칭 직후 인프라 및 핵심 기능 검증
- [ ] **인프라 가용성**: Vercel 프로덕션 도메인 응답 상태 확인 (`HTTP 200 OK`).
- [ ] **정적 에셋 로드**: Pretendard 폰트, Tailwind CSS, 코어 JS 로드 지연 없음 확인.
- [ ] **Zero-Key 확인**: 외부 LLM/AI API 호출 요청이 0건인지 브라우저 네트워크 탭 확인.
- [ ] **Zero-PII 확인**: 입력 필드에 입력된 텍스트가 서버 로그나 원격 분석 도구로 유출되지 않는지 확인.

### [H+2 ~ H+8] Safety & 핵심 흐름 확인
- [ ] **Safety Crisis 감지**: "죽고 싶다", "사라지고 싶다" 등 위기어 입력 시 비의료 응급 기관(1393, 1577-0199) 안내 모달 100% 발화 확인.
- [ ] **1-Minute MyungSim 흐름**: SCAN → SYNC → SHIFT 3단계 완료 후 로컬 저장소 기록 정상 작동.
- [ ] **200개 카드 및 PACK 01~10 무결성**: 카드 열람, 태그 필터링, 검색 정상 동작.

### [H+8 ~ H+24] 크래시 및 예외 관제
- [ ] **JS Uncaught Exception**: 브라우저 콘솔 크래시율 0.05% 미만 유지.
- [ ] **로컬 스토리지 쿼터**: 브라우저 스토리지 할당량 초과 에러 0건.
- [ ] **P0/P1 버그 모니터링**: 서비스 접속 불가, 데이터 손실 등 치명적 결함 유무 확인.

## 3. 첫 24시간 절대 금지 행동 (Do Not Change Today)
> [!CAUTION]
> 첫 24시간 동안은 다음 행위를 절대 금지합니다.
> 1. 카드 문구, 오탈자(단순 표기오류 제외), 뉘앙스 수정 금지.
> 2. RuleBasedRouter 키워드 매칭 가중치 변경 금지.
> 3. 홈 화면 UI 레이아웃, 버튼 색상, 안내 텍스트 변경 금지.
> 4. 소표본 이탈률에 기반한 기능 개선 논의 금지.
